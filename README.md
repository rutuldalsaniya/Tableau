# Tableau Sales Dashboards

Tableau dashboards analysing retail sales data, built by **Rutul Dalsaniya**.

## Dashboards

| File | Description |
|---|---|
| `Amazon sales dashboard.twbx` | Sales dashboard built on Amazon sales data |
| `walmart sales data analysis.twbx` | Sales analysis built on Walmart sales data |

## How to open

Download a `.twbx` file and open it in [Tableau Desktop](https://www.tableau.com/products/desktop) or the free [Tableau Public](https://public.tableau.com/) app. The data is packaged inside each workbook.
